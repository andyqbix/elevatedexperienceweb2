# Images for the HX | Hive eXperience page (/hx-hive-experience/)

Drop the supplied artwork into this folder using these exact file names (PNG, JPG or WebP all work).
The page picks them up on the next build and optimises them automatically.

| File name | What it is |
|---|---|
| `hx-belonging-knot.png` | Belonging Knot with HX logo (copper artwork). Also used as the social sharing image. |
| `hx-cx-dx-ex-diagram.png` | CX / DX / EX diagram (Why HX section) |
| `hx-screen-home.png` | HX home screen screenshot |
| `hx-screen-your-hives.png` | "Your Hives" switcher screenshot |
| `icons/HXCafe.jpg` ... `icons/HXPayment.jpg` | The 13 app icons, named as supplied |

Icon names: HXCafe, HXChats, HXEvents, HXSchool, HXMarketPlace, HXBusiness, HXWebsiteBuilder,
HXCommunity, HXNoticeboard, HXRadio, HXAI, HXSocialMediaConnector, HXPayment.
